Note for this project
---------------------

`src/strokes.js` is generated from KanjiVG by `npm run strokes`. It is a subset
of the original data, reduced to the characters this deck uses and rounded to
one decimal place, and it is therefore a derived work carrying this same
share-alike licence. That is a stronger condition than the SIL Open Font
Licence covering the bundled typeface (public/fonts/OFL.txt) — the two are not
interchangeable.
