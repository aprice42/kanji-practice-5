# Hiragana

<!-- The hiragana syllabary, 46 basic characters.

     The READING is the sound, written in romaji — the one place in this project
     romaji is allowed, because for a child learning kana the sound IS the
     lesson rather than a crutch. See README.md, Non-goals.

     Hepburn: shi, chi, tsu, fu. One deliberate departure — を and ヲ are "wo"
     rather than Hepburn's "o". That is what beginner charts teach, and "o"
     would collide with お/オ, which is a real ambiguity rather than a spelling
     preference.

     There is no MEANING, and that is not an unfinished row. A kana is a sound,
     not a word. -->
